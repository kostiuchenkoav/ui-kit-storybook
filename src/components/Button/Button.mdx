# Button

Основная кнопка действия. Используйте `variant`, чтобы показать важность действия:

- `primary` — главное действие на экране (одно на блок).
- `secondary` — второстепенное действие, например «Отмена».
- `danger` — необратимое действие, например «Удалить».

По умолчанию кнопка имеет `type="button"`. Для отправки формы передайте `type="submit"`.
