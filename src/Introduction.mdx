# UI-библиотека

Набор доступных React-компонентов на TypeScript. Каждый компонент описан здесь, протестирован и проверен на соответствие правилам доступности (axe).

## Установка

```bash
npm install @kostiuchenkoav/ui-kit
```

```tsx
import { Button, Input, Modal, Tabs } from '@kostiuchenkoav/ui-kit';
import '@kostiuchenkoav/ui-kit/styles.css';
```

## Принципы

- **Доступность по умолчанию.** Подписи, фокус, `aria-*` и клавиатурная навигация встроены в компоненты.
- **Токены вместо констант.** Цвета, отступы и радиусы берутся из CSS-переменных `--uk-*`, их можно переопределить.
- **Тёмная тема.** Токены переключаются через `prefers-color-scheme`.
